# AnimeBook-Rawi-
# 🎭 راوي | Rawi - عالم القصص الواقعية 🇾🇪

**قصص من حياتنا.. بأسلوب الأنمي الاحترافي.**

"راوي" هو أول تطبيق يدمج بين الواقع اليمني وفن الأنمي العالمي. هنا لا نقرأ دروساً، بل نعيش قصصاً واقعية، مواقف من الشارع، ودراما اجتماعية تلمس كل واحد فينا.

## ✨ ماذا ستجد في "راوي"؟
* **🎬 دراما واقعية:** قصص مستوحاة من أحداث حقيقية ومواقف يومية يعيشها الشباب.
* **🖼 فن بصري مذهل:** جودة تصوير سينمائية (Cinema 4D Rendering) مع تركيز عالي على ملامح الشخصيات (Facial Geometry) لتشعر بكل شعور يعيشه بطل القصة.
* **🇾🇪 نكهة محلية:** الشخصيات تلبس مثلنا، تتكلم بلهجتنا، وتتحرك في أماكن تشبه حاراتنا وجبالنا.
* **📱 تجربة تفاعلية:** أنت لا تشاهد فقط، بل تتنقل بين أحداث القصة بلمسة إصبع.

## 🛠 خلف الكواليس:
المشروع مبني ليكون منصة مرنة تدعم المبدعين في سرد قصصهم بأقل التكاليف وبأعلى جودة بصرية ممكنة باستخدام الذكاء الاصطناعي و React Native.
